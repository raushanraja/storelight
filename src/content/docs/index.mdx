## What it does

<CardGrid stagger>
	<Card title="Point it at any folder" icon="setting">
		Add one or more directories in **Settings**. Include and exclude globs decide which `.md`
		files appear. Paths are guarded server-side.
	</Card>
	<Card title="A real WYSIWYG editor" icon="pencil">
		The Studio uses Milkdown Crepe for rich editing and CodeMirror for raw Markdown. Frontmatter
		is preserved and editable separately.
	</Card>
	<Card title="Edit the rendered page" icon="rocket">
		In the browse view, click a paragraph, heading, table, or code block to edit its Markdown.
		Task checkboxes toggle and save instantly.
	</Card>
	<Card title="Autosave + auto-commit" icon="approve-check">
		Changes are written to disk as you type. After a short pause, Storelight commits just that
		file to its own git repository with an action-specific message.
	</Card>
</CardGrid>

## Try it

Use the bundled **Demo docs** root to play with checkboxes, inline edits, and revision history. When you're ready, add your own folder from [Settings](/studio/settings).
