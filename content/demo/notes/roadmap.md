# Roadmap

Check something off, then open **History** in the Studio to see the commit that Storelight created for it.

## Editor

- [x] Rich Markdown editing with Milkdown Crepe
- [x] Raw Markdown mode with CodeMirror
- [ ] Slash-command cheatsheet inside the editor
- [ ] Image upload that writes beside the Markdown file
- [ ] Split-pane preview on wide screens

## Inline editing

- [x] Source offsets on rendered blocks
- [x] Live task checkboxes
- [x] Per-block Markdown dialog
- [ ] Edit a table cell instead of the whole table
- [ ] Multi-block selection

## Git

- [x] Commit only the edited file
- [x] Debounced auto-commit with action-specific messages
- [x] Per-file revision history and diffs
- [ ] Restore a previous revision from the history drawer
- [ ] Optional push after commit

## Housekeeping

- [ ] Add a file-creation action to the Studio tree
- [ ] Rename and move files without leaving the app
